# Piyush Tiwari | Portfolio
 
My personal portfolio website. It shows who I am, my skills, and the projects I have built while studying B.Tech Computer Science and Engineering.
 
Live site: https://portfolio-phi-fawn-98dglblujq.vercel.app
 
## What is on the site
 
- About, skills, projects and goals sections
- A contact form that sends messages straight to my email
- A privacy policy page at `/privacy`
- A small terminal window (click the terminal button in the corner)
- Dark theme, sound toggle (off by default)
## Built with
 
- Next.js and React
- TypeScript
- Tailwind CSS
- Framer Motion for animations
- Resend for contact form emails
- Hosted on Vercel
